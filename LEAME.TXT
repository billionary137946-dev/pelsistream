             Ya no hay backend en Python -- se borró (pelisback) para poder

4) DESPLIEGUE A VERCEL
--------------------------
Un solo proyecto de Vercel apuntando a la carpeta pelisfront/. Variables de
entorno a configurar en Vercel (Project Settings → Environment Variables):
  DATABASE_URL, JWT_SECRETO, JWT_HORAS_EXPIRACION
Falta crear el repositorio git (todavía no existe) antes de conectar Vercel
a GitHub, o usar `vercel` CLI directo sin git.
